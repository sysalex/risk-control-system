# 阶段 10：质量保障 — 规格文档

## 背景与目标

阶段 0-9 已完成全部功能开发。本阶段目标是通过测试补齐、安全审查和性能基准，确保系统在合并到 `main` 前达到生产就绪标准。

## 范围

- 后端：统一集成测试基类、端到端 API 链路测试、低覆盖率模块补齐
- 前端：E2E 测试框架（Playwright）+ 核心流程覆盖
- 安全：按 OWASP Top 10 逐项代码审查
- 性能：后端 API P99、前端首屏 LCP 基线记录

## 非范围

- 不引入 Testcontainers（当前用 `@MockBean` 模式，真实 DB 集成后续迭代）
- 不配置 CI/CD 流水线

## 关键决策

| 决策 | 选择 | 原因 |
|------|------|------|
| E2E 浏览器 | 本地 Google Chrome (`channel: 'chrome'`) | 减少额外下载，直接使用用户已有环境 |
| 测试数据库 | 本地 MySQL | 用户要求，已在 `application-test.yml` 配置 |
| Flyway 测试策略 | `enabled: false` | 当前测试全部 `@MockBean`，不访问真实数据库 |
