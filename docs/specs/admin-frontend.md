# 管理员前端功能规格

## 目标

- 提供用户管理页面，支持查看用户列表、创建用户、删除用户。
- 提供规则管理页面，支持查看规则列表、创建规则、删除规则、启用/停用规则。
- 将用户管理和规则管理接入主布局路由。

## 非目标

- 本阶段不实现复杂弹窗编辑器和条件/动作 JSON 可视化配置。
- 本阶段不实现前端权限菜单动态裁剪。
- 本阶段不实现批量操作、导入导出和高级筛选。

## 页面

- `/users`：用户管理。
- `/rules`：规则管理。

## 验收标准

- 用户管理页进入后加载用户列表。
- 用户管理页可以提交新增用户请求，并刷新列表。
- 规则管理页进入后加载规则列表。
- 规则管理页可以提交新增规则请求，并刷新列表。
- 规则管理页可以启用/停用规则，并刷新列表。
- 路由可以解析 `/users` 和 `/rules`。
