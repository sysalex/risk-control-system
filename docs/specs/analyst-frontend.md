# 前端分析师功能规格

## 目标

补齐分析师日常处置入口，让前端可以查看风险事件、触发事件处理、查看风险评分与决策记录，并查看审计日志。

## 非目标

- 不新增后端 API。
- 不调整权限模型。
- 不实现复杂筛选、详情抽屉或批量操作。

## 验收标准

- `/events` 展示风险事件列表，并支持对未处理事件调用处理接口。
- `/decisions` 展示风险评分和决策记录，并支持按用户 ID 触发重新评分。
- `/audit-logs` 展示审计日志列表。
- 三个页面接入主布局路由，现有侧边栏链接可访问。
- 新增页面具备 Vitest 单元测试，覆盖数据加载、渲染和关键操作。

## Clarify

无待确认问题。默认复用阶段 7 已封装的 `eventApi`、`scoreApi`、`decisionApi`、`auditApi`，本阶段仅完成列表和关键动作入口。
